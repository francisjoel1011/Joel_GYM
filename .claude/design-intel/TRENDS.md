## 2026-09-17 — initial scouting for JOEL GYM build

Anchors re-verified live (per standing ritual) plus targeted research into fitness/gym/bold-industrial-brand sites specifically, since the generic elite-web bar (landonorris.com, wings.design) needed grounding against this brand's actual black/red/brick/industrial identity.

### 1. landonorris.com (anchor, re-verified today)
- **Tap-to-lock hero interaction**: scroll momentum pauses during the hero to force a beat of attention before releasing the user into the main scroll. Cheap to approximate (a scroll-jack on the first viewport only) and gives a hero real weight instead of just autoplaying past it.
- **Base/hover image-pair microinteractions** on gallery-style modules (helmet hall of fame): each item swaps to a second image state on hover rather than just scaling/shadowing.
- **Vertical-to-horizontal layout pivot** signals a content-category change (hero sequence → horizontal helmet gallery). The shift in scroll axis itself communicates "you've entered a different kind of section."
- **Where it applies**: the vertical→horizontal pivot is a near-literal fit for a "walk the floor" facilities passage — three zones of a gym mapped to a horizontal pinned scroll instead of another vertical stack. The base/hover pairing is a cheap, tasteful gallery microinteraction.

### 2. wings.design (anchor, re-verified today)
- **Grayscale-first palette discipline**: color is used functionally (progress indicators, live states), not decoratively. Client logos stay monochrome so nothing competes with the studio's own palette.
- **One repeated microcopy motif** ("//") stitches every section into a single voice — homepage tagline, section kickers, and the contact CTA all reuse it.
- **Where it applies**: JOEL GYM already has repeated brand language in the physical space ("NEVER GIVE UP", "JOIN TO FIT") — that can play the exact role wings.design's "//" plays: a verbal tic reused as a structural design element (ribbon/marquee, section kickers), not just as one hero headline used once and dropped.

### 3. USAvionix by basement studio — Awwwards SOTD, industrial/aerospace sector
- Near-monochrome palette (pure black/white) scored 8.2/10 on animation craft and 8/10 on creativity — proof that extreme color restraint reads as premium in an *industrial/technical* category, not only in SaaS minimalism.
- **Where it applies**: validates JOEL GYM's rule of "one accent color doing work at a time" (see BRIEF.md palette section) — basement studio gets richness from motion and type, not from adding more hues. Same logic should keep gold rare and reserved rather than blended through the palette.

### 4. Mission MMA (Chicago) — missionmmachicago.com, live combat-gym site
- Dark ground + **Bebas Neue** condensed display type reads as "fight-poster," industrial-edged branding specifically within the combat-sport/gym category (not generic "sports").
- **Where it applies**: direct validation for JOEL GYM's type system — a heavy condensed face (Anton) for the loudest moments, a lighter condensed face (Bebas Neue) for the supporting tier. See BRIEF.md type direction.

### 5. Anti-pattern — American Combat Gym (via search, not visited live)
- Reported to combine glassmorphic UI panels with an autoplay video hero. Reads as generic-trendy rather than authentic-industrial — glassmorphism undercuts a brand built on exposed brick/steel/concrete.
- **Where it applies**: explicit counter-example. If JOEL GYM's build ever reaches for frosted-glass cards "because gym sites can be modern too," reject it — it isn't this brand's modern.

### 6. Anti-pattern — "Liquid Glass Hero Section" (spotted on recent.design/godly.website's current feed)
- Apple's glass-morphism visual language is actively trending across the wider 2026 web right now, which is precisely why it will keep surfacing as a tempting default. Named here as a live, current temptation, not a stale banned-list item — flag it explicitly rather than assume it's already out of fashion.

### 7. Current Awwwards SOTD wave (Sep 2026) — craft floor, not palette reference
L.I.S.A. (Locomotive), Léo Parpeix Portfolio 2026, MONOGRID's "The Tuscan Journey Begins," HOLOGRAPHIK's Paul Kalkbrenner site. None are fitness-relevant in subject matter, but they set the *craft floor* JOEL GYM must clear regardless of genre: editorial pacing, developer-award-level animation polish (smooth, purposeful, never default-eased), restraint. Useful as a check on execution quality, not on look.

### 8. General fitness-web trend confirmation (search, not individually verified live)
Multiple 2026 fitness-site trend roundups converge on dark-mode-first + bold oversized type + a single saturated accent (red is explicitly named as a recurring choice, e.g. "IronGrind," "GoodLife Fitness") as the dominant current direction for the category. Treat as directional confirmation that the approved black/red/gold plan is on-trend, not as specific sites to copy — none were verified live and the listicle sources are low-rigor.
